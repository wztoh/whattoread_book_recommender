# WhatToRead : Your digital librarian
WhatToRead is book recommender powered by Large Language Models(LLMs), with RAG implementation using live web results. It gives book recommendations curated to your preferences, and directs you to local libraries with book availability.
 [!NOTE]
> This project is done in Python 3.14.

| Feature | Status | Notes |
|---------|--------|-------|
| Gemini | ✅ | Main LLM |
| Tavily | ✅ | Web search |
| NLB API | ✅ | Library lookup |
